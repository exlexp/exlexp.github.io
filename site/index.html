ISOLATED WEB APP / NO DEVELOPER BACKEND

Messages without our middleman.

Relayless connects an installed Chrome IWA directly to a user-selected XMPP provider and, when the audited WASM adapter is complete, the public Tox network. We run no account, proxy, analytics, logging, relay, or message server.

Install

Requires current Chrome with the applicable IWA unmanaged or enterprise installation policy. Download the Signed Web Bundle from GitHub Releases, verify its SHA-256 checksum and signature, then install it through Chrome's IWA flow.

Privacy

Profiles, credentials, contacts, and history are encrypted locally. Third-party XMPP providers and Tox participants still see the metadata inherent to those protocols. There are no cookies, forms, trackers, or runtime CDN requests on this page.

Verify

Compare sha256sum relayless.swbn with SHA256SUMS, inspect the bundle with wbn-sign info, and review the published source at the matching tag.
