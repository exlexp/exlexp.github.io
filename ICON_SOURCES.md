# Icon sources

- Interface icons: [Lucide](https://github.com/lucide-icons/lucide), package version 1.29.0, ISC license.
- XMPP mark: [Simple Icons](https://github.com/simple-icons/simple-icons), package version 16.28.0, CC0-1.0 license.
- Tox application mark: [`img/icons/qtox.svg`](https://github.com/qTox/qTox/blob/master/img/icons/qtox.svg) from the qTox project, GPL-3.0 license.

The application imports Lucide and Simple Icons from their npm packages. The qTox mark is kept as the original public asset; it has not been redrawn.
